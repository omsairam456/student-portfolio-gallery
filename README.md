# 👩🏻‍💻 Malla Reddy Students Portfolio Gallery

## 📌 About the Project

The **Malla Reddy Students Portfolio Gallery** is a website developed using HTML and CSS to showcase the talents, skills, achievements, and interests of students.

The website displays student profiles in an organized gallery with individual portfolio links. It provides a simple and attractive way to present students' technical skills, academic interests, and accomplishments.

This project was created as a beginner-friendly web development project to practice HTML and CSS.

## ✨ Features

- 🎓 Displays four student profile cards.
- 🖼️ Includes student profile images.
- 💻 Shows student skills and interests.
- 🏆 Highlights student achievements.
- 🔗 Provides links to individual student portfolios.
- 🎨 Uses attractive colors, card layouts, and hover effects.
- 📱 Responsive gallery layout for different screen sizes.
- ♿ Includes visible keyboard focus styles and reduced-motion support.

## 🛠️ Technologies Used

- **HTML5** – To create the structure and content of the website.
- **CSS3** – To style the website, design the student cards, create hover effects, and make the layout responsive.

## 📂 Project Structure

The project contains the following files:

```text
Student-Portfolio-Gallery/
│
├── index.html
├── style.css
├── Maha.html
├── Sahasra.html
├── Bhavana.html
├── Abhi.html
└── README.md
```

**File descriptions:**

- `index.html` – The main page displaying the student portfolio gallery.
- `style.css` – Contains the styles and responsive layout for the website.
- `Maha.html` – Individual portfolio page for Sreemahalaxmi.
- `Sahasra.html` – Individual portfolio page for Sahasra Reddy.
- `Bhavana.html` – Individual portfolio page for Bhavana.
- `Abhi.html` – Individual portfolio page for Abhinaya.
- `README.md` – Explains the project and how to run it.

*Note: The individual HTML files should exist in your project folder for the portfolio links to work.*

## 🎯 Purpose of the Project

The main purpose of this project is to learn the fundamentals of web development and create a platform to showcase student skills and achievements.

It helps beginners practice HTML elements, CSS selectors, grid layouts, responsive design, and hover effects.
